# Clove Dental Landing Page

A responsive React landing page built with Vite, matching the Clove Dental design.

## Run locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open the local URL shown in the terminal.

## Build for production

```bash
npm run build
```

## Notes

- Mobile navigation toggle and FAQ accordion interactions are implemented.
- Responsive styles are included for desktop, tablet, and mobile screens.
- Add a GitHub repo and deploy to Netlify, Vercel, or GitHub Pages to publish a live URL.
